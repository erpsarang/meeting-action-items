# 회의록 할 일 정리 (meeting-action-items)

회의가 끝난 뒤 Markdown 회의록을 붙여 넣으면, 누가 언제까지 무엇을 하기로 했는지 할 일 목록으로 정리해 주는 웹 App이다. 규칙으로 정리하며 AI를 호출하지 않는다.

## 지금 상태

회의록을 붙여 넣으면 `이름: 할 일` 줄을 뽑는다. 체크박스(`[ ]`, `[x]`)가 있거나 줄 끝 괄호에 기한이 있는 줄은 담당자별로 묶는다. 둘 다 없는 줄은 같은 회의록에서 이미 할 일의 담당자로 나온 이름이면 그 사람 묶음에 넣고, 아니면 목록 맨 아래 "확인이 필요한 줄"에 모아 보여 준다(줄을 지우지 않는다). 기한은 `(10/15)`, `(10월 15일)`, `(2026-10-15)`, `(2026/10/15)` 형식을 인식하며 어느 형식이든 같은 기한으로 취급하고 화면에는 쓴 그대로 보여 준다. `13월 40일`처럼 없는 날짜와 `내일`, `다음 주`, `곧` 같은 표현은 기한으로 보지 않는다. 묶음 안에서 기한이 빠른 순으로 보여 주며, 연도가 적힌 날짜는 연도까지 비교한다. 연도가 있는 기한과 없는 기한이 섞이면 연도 없는 기한은 같은 묶음에 적힌 연도로 보고 월·일로 비교하므로, 같은 날짜는 형식과 상관없이 같은 기한으로 취급되어 적힌 순서를 따른다. 연도가 적힌 기한이 없는 묶음에서는 연도 없는 날짜의 연도를 회의록을 붙여 넣은 날짜 기준으로 정하고, 약 6개월(183일)을 넘게 지난 월·일은 다음 해로 보므로 12/30과 1/5처럼 연말과 연초가 섞여도 실제 기한이 빠른 순으로 나온다. 화면과 복사한 글에는 기한을 쓴 그대로 보여 준다. 기한이 없는 할 일은 묶음의 맨 아래에 나오고, 완료 표시(`[x]`)한 할 일은 목록에 남되 완료로 구분된다. `안건`, `결정`은 담당자로 보지 않고 제외한다. 담당자 묶음마다 "복사" 버튼이 있어, 누르면 그 사람의 할 일이 `이름` 줄과 `- 할 일 (기한)` 줄(화면 순서, 기한은 쓴 그대로, 기한이 없으면 괄호 없이)로 클립보드에 복사되고 버튼 글자가 잠깐 "복사됨"으로 바뀐다. 클립보드 쓰기에 실패하면 버튼 글자가 잠깐 "복사 실패"로 바뀌고 같은 복사용 글을 직접 선택해 복사할 수 있게 그 묶음 안에 보여 준다. 완료(`[x]`) 항목은 복사에서 빠지며, 묶음의 항목이 모두 완료면 버튼을 누를 수 없다. "확인이 필요한 줄"에는 복사 버튼이 없다. `1. 김철수: 견적 회신`처럼 `이름: 할 일` 모양이 아니어도 줄 안에 `:` 또는 `：`가 있으면 읽지 못한 줄도 지우지 않고 "확인이 필요한 줄"에 쓴 그대로 보여 준다(`안건`, `결정` 줄 제외). 할 일이 하나도 없고 입력이 비어 있지 않으면 "할 일이 없습니다." 대신 `이름: 할 일` 형식으로 쓰면 인식된다는 안내와 예시를 보여 주고, 입력 칸 아래에도 인식되는 형식을 한 줄로 적어 둔다. 번호 목록, 굵은 이름, 이름 뒤 괄호, 여러 담당자, 하이픈 구분을 할 일로 새로 인식하는 것은 후속 범위다. 화면은 SAP Fiori Horizon 계열 구성으로, 페이지 머리 아래에 회의록 입력 섹션과 할 일 결과 섹션이 나뉘어 있고 복사 버튼은 Fiori Default 스타일이다. CSS만 사용하며 새 의존성과 외부 글꼴·스크립트가 없다('72' 글꼴은 설치된 경우에만 쓰고 없으면 Arial로 대체한다). 키보드 포커스 표시가 있고 좁은 화면에서도 깨지지 않는다. 기능은 요구 Issue를 하나씩 받아 만든다.

## 실행

```bash
npm install
npm run dev     # 개발 서버
npm test        # 타입 검사, 빌드, 테스트
npm run build   # 배포용 빌드 (dist/)
```

Framework 버전과 개발 흐름은 [`FRAMEWORK.md`](FRAMEWORK.md)에 있다.
